# BuildCraft Community Edition

**An unofficial port of BuildCraft 8.0.0 and BuildCraft 7.1.27 to newer versions of Minecraft.**

Why BC8 + BC7? BuildCraft 8 is the latest release with a fresh take on classic BuildCraft mechanics, but not all mechanics from BuildCraft 7 were implemented in BC8, such as robotics and building features.

## Roadmap

*   Port robotics (ready)
*   Port builders (ready)
*   Move from alpha to beta (ready)
*   Global project checkup (ready)
*   Forge release for 1.19.2 Forge (ready)
*   Port to 1.20.1 Forge (ready)
*   Backport to 1.12.2 (current subtask)
*   Port to 1.21.1 Forge (beta)
*   Port to NeoForge/Fabric
*   Port to 1.21.11

## Current Status

Now in mod available 100% of content from BC8 and BC7

- 1.19.2 Forge - 100%
- 1.20.1 Forge - 100%
- 1.21.1 Forge - beta > 99% functionality
- 1.21.1 NeoForge - work in progress
- 1.12.2 Forge - work in progress (low priority)
