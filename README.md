# BuildCraft Community Edition

**An unofficial community port of BuildCraft 8.0.0 and BuildCraft 7.1.27 to newer versions of Minecraft.**

BuildCraft Community Edition aims to preserve classic BuildCraft mechanics while bringing them to modern Minecraft versions.

Why BC8 + BC7?
BuildCraft 8 is the latest release with a fresh take on classic BuildCraft mechanics, but not all mechanics from BuildCraft 7 were implemented in BC8, such as robotics and building features.

## Roadmap

- Port robotics
- Port building features
- Stabilize the codebase
- Move from alpha to beta
- Release

## Current Status

- Main content has been ported and is working successfully
- Robotics are in progress
- Building features are in progress
