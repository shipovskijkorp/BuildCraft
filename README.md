# BuildCraft Community Edition

**An unofficial port of BuildCraft 8.0.0 and BuildCraft 7.1.27 to newer versions of Minecraft.**

Why BC8 + BC7? BuildCraft 8 is the latest release with a fresh take on classic BuildCraft mechanics, but not all mechanics from BuildCraft 7 were implemented in BC8, such as robotics and building features.
