<chapter name="Career"/>
This career is programmed into a Redstone Board for 32,000 MJ and installed into an empty Robot with an Integration Table.

While active, the robot fetches a suitable cutting tool and removes leaf blocks in its work zone. It returns to compatible Docking Stations to recharge, load or unload as required.
