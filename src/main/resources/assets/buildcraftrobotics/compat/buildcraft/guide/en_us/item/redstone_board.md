<lore>
A machine can move, but without a board it has no idea whether it should carry, plant, mine or flee from the nearest cow.
</lore>
<no_lore>
A Redstone Board stores the career program installed into a Robot.
</no_lore>
<hint>
<bold>Hint:</bold> Store programmed boards by career in separate labelled inventories. Keeping an unprogrammed board nearby makes reconfiguration faster.
</hint>


<recipes_usages stack="buildcraftrobotics:redstone_board"/>

<chapter name="Programming"/>
Place a blank board in a Programming Table, select a career and supply laser power. Blank boards stack to sixteen; programmed boards stack to one.

Programming costs depend on the career: basic logistics boards require 8,000 MJ, common work boards 32,000 MJ, advanced combat or delivery boards 64,000 MJ, and the Builder board 128,000 MJ.

<chapter name="Installing"/>
Use an Integration Table to combine the programmed board with an empty Robot. Installing a board requires 10,000 MJ. The resulting Robot keeps that career until rebuilt with a different board.
