<chapter name="Career"/>
This career is programmed into a Redstone Board for 8,000 MJ and installed into an empty Robot with an Integration Table.

While active, the robot collects dropped item entities inside its work zone, applies the linked station item filter, then returns to unload them. It returns to compatible Docking Stations to recharge, load or unload as required.

Use Gate filters and Lists on the linked stations to restrict which items are handled.
