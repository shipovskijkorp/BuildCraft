<chapter name="Career"/>
This career is programmed into a Redstone Board for 64,000 MJ and installed into an empty Robot with an Integration Table.

While active, the robot fulfils item requests exposed by Requesters and station request actions. It returns to compatible Docking Stations to recharge, load or unload as required.

Use Gate filters and Lists on the linked stations to restrict which items are handled.
