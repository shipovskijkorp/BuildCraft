<chapter name="Powering Tables"/>
Place Lasers within six blocks of an Assembly, Charging, Integration, Advanced Crafting or Programming Table and supply the Lasers with MJ. Each Laser automatically searches for a compatible table that currently requests power.

A Laser can transfer up to 6.4 MJ per tick. Multiple Lasers may work on the same table, and their beams move as table demand changes.
