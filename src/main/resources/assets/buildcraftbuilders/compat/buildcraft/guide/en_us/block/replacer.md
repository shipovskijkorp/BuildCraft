<chapter name="Replacing Blocks"/>
Place the used Blueprint in the Blueprint slot. Record the block to find in one Single Block Schematic and the replacement block in the other. The Replacer edits the Blueprint data and returns the modified design.

The machine changes the plan, not blocks already placed in the world. Both schematics are consumed by a completed replacement operation.
