<lore>
Pipes move resources. Robots move themselves, the resources and sometimes everything standing in the way.
</lore>
<no_lore>
A Robot is a mobile worker whose behaviour is determined by an installed Redstone Board.
</no_lore>
<hint>
<bold>Hint:</bold> Start with one robot, two reachable Docking Stations and a small work zone. Expand only after charging, tool collection and unloading all work reliably.
</hint>


<recipes_usages stack="buildcraftrobotics:robot"/>

<chapter name="Creating a Robot"/>
Program a blank Redstone Board in a Programming Table, then install the programmed board into an empty Robot with an Integration Table. Different boards create different robot careers.

<chapter name="Deploying and Charging"/>
Attach a Docking Station to a pipe, then use the programmed Robot on that station. The placing player becomes its owner. A station connected to MJ can recharge its docked robot.

Robots keep a safety energy reserve and return to a suitable station when they need to recharge, load or unload. Gate actions on Docking Stations control filters, routes, work zones and which resources are available.
