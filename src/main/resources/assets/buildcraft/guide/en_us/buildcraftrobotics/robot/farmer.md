<chapter name="Career"/>
This career is programmed into a Redstone Board for 32,000 MJ and installed into an empty Robot with an Integration Table.

While active, the robot fetches a hoe and prepares suitable dirt or grass blocks for planting. It returns to compatible Docking Stations to recharge, load or unload as required.

The robot obtains the required tool from a station. Use station filters to control which tools it may take and where damaged tools are returned.
