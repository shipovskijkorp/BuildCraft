<lore>
Moving four Land Marks every time a project changes size quickly becomes a project of its own.
</lore>
<no_lore>
A Volume Box is a movable area marker controlled with the Marker Connector.
</no_lore>
<hint>
<bold>Hint:</bold> Volume Boxes are convenient for moving a finished area definition between machines. Rename or store them separately when several projects use similar dimensions.
</hint>


<recipes_usages stack="buildcraftcore:volume_box"/>

<chapter name="Placing and Resizing"/>
Use the item on a block to create a Volume Box beside it. Click one of the box handles with the Marker Connector, move the selected corner, then click again to finish resizing.

Sneak-use the Marker Connector on the box to remove it. Machines next to the box can use the selected volume in the same way as a Land Mark area.

<chapter name="Add-ons"/>
A Volume Box can hold compatible planning add-ons. The Filler Planner stores a Filler pattern and inversion state in the box so a nearby Filler can adopt them automatically.
