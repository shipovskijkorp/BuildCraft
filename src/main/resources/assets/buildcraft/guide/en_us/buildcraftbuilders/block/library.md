The Electronic Library transfers Blueprint and Template data between snapshot items and the saved snapshot database.
</no_lore>
<hint>
<bold>Hint:</bold> Use one Library as the project archive and another near the work site. This separates protected master plans from temporary working copies.
</hint>


<recipes_usages stack="buildcraftbuilders:library"/>

<chapter name="Downloading"/>
Insert a used Blueprint or Template whose design exists in the world snapshot database. After the transfer completes, the design is copied into the local library data used by the client interface.

<chapter name="Uploading"/>
Select a stored design in the Library interface and insert a clean Blueprint or Template into the upload slot. The Library transfers the selected snapshot to the server and produces a used snapshot item.

Each transfer takes 50 ticks. Do not remove the input while its progress bar is moving.
